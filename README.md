# 🎮 Simon Says Memory Game

##  Overview

This is a classic Simon Says memory game built using HTML, CSS, and JavaScript. The game challenges players to remember and repeat an increasingly long sequence of colors.


##  Features

*  Interactive gameplay
*  Random color sequence generation
*  Visual feedback (flash effects)
*  Score and High Score tracking
*  Increasing difficulty with each level


##  Technologies Used

* HTML5
* CSS3
* JavaScript (DOM Manipulation & Events)

##  Project Structure

Simon-Says-Game/
│── index.html
│── style.css
│── app.js


##  How to Play

1. Press any key to start the game
2. Watch the color sequence shown by the game
3. Click the buttons in the same order
4. Each level adds a new color to the sequence
5. Game ends if you click the wrong button
